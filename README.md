# Network Traffic Analysis with Wireshark

## Project Overview

This project documents the analysis of network traffic using Wireshark as part of a cybersecurity laboratory focused on network monitoring, protocol identification, and security assessment.

The objective was to understand how devices communicate across a network and identify potential security risks through packet inspection.

---

## Objectives

* Capture network traffic
* Identify active devices
* Analyze communication patterns
* Inspect network protocols
* Detect potential security issues
* Improve visibility into network activity

---

## Tools Used

* Wireshark
* Kali Linux
* Windows Systems

---

## Activities Performed

### Packet Capture

Captured network packets generated by devices connected to the network.

### Protocol Analysis

Analyzed protocols including:

* TCP
* UDP
* DNS
* HTTP
* HTTPS
* ICMP

### Network Monitoring

Observed communication between hosts and identified common network services.

### Security Assessment

Reviewed traffic for unusual activity and evaluated potential exposure of network services.
